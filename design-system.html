Gallium

IBM Carbon's colour, type and accessibility with Figma's density and softness. Carbon's button kinds, one container, one focus ring, three radii and one control height.

Seven rules

Each rule settles one recurring decision, so it never has to be made twice.

1 · One height32px for every button, input, select, tab and stepper. Things on one row always align.
2 · Three radii4 control · 8 container · pill (+ 2 xs for glyph shapes). Nested radius = outer − padding.
3 · Carbon colour, unmodifiedEvery colour is a Carbon v11 token value, in White and G100. No custom hex.
4 · Flat at restHairlines define structure. Shadows only on menus, popovers, modals and toasts.
5 · One focus ring2px --cf-focus. Outside by default, inside when flush.
6 · One job, one componentRegions are head · content · foot. Figures are .cf-kpi, fields are .cf-prop, in-place edits are .cf-edit.
7 · Numbers in Plex SansTabular figures. Right-aligned in table columns, left in property lists. Mono only for code, formulas and identifiers.

Button

One class, .cf-btn, with Carbon's kinds and colours. Kind, size and shape are independent modifiers. State comes from the browser or ARIA, never from a class.

Anatomy

Height 24 / 32 / 40 / 48 from --cf-h-* Padding 8 / 12 / 16 / 16, minus 4px on the icon side Gap 8px (4px at xs) · Icon 16px Carbon, fill:currentColor Label 14px / 500 / .16px in a <span>, truncates with ellipsis Radius 4px · Border 1px inset shadow (no layout shift)

Hierarchy: Carbon's four kinds + danger

Primary · button-primary blue-60. The one action that moves the task forward.
Secondary · button-secondary gray-80. Paired with a primary: Cancel, Back.
Tertiary · button-tertiary blue outline. Standalone or third action.
Ghost · link-primary text. Toolbars, rows, low-stakes actions.
Danger · primary, tertiary, ghost. Hover always fills red-60-hover.

Icons

The official IBM Carbon icon set, built from @carbon/icons into one SVG sprite. Icons inherit currentColor, so buttons, menus and notifications colour them. Symbol IDs are Carbon's own names with an icon-- prefix.

The script reads Carbon's icon descriptors, writes icons/carbon-icons.svg and inlines the sprite between the carbon-icons:start/end markers, so pages also work from file://. Unknown names are reported.

Data and inspector

Every piece of data has one component. The same driver, "Time saved", appears below on the canvas and in the inspector. Labels, values, numbers and edit behaviour match, because both views use the same parts.

When you need to…UseRule
Show one headline figure.cf-kpiLabel 12 · value heading-04 (tabular) · meta 12 helper. Standalone has no padding.
Show several figures.cf-kpis · .cf-kpis.is-rowVertical list in a panel; strip with heading-05 values on a results page.
Read or edit one object's fields.cf-props › .cf-propLabel column 45% (min 96px). Value is .cf-edit (editable) or .cf-prop-o (computed, secondary). Long text: .is-stacked.
Read or edit many records with the same fields.cf-table (.is-editable)Editable cells are the same .cf-edit as the inspector.
Rename in place.cf-edit.is-title · .is-title-smPage title heading-04; object name in the inspector heading-02.
Fill a form (modal, settings).cf-field › .cf-inputLabel above, filled 32px field. Not used in the inspector.
Show status or trust.cf-tag · .cf-dot + labelTag in tables, dot in property labels and legends. Never colour alone.
Show a number anywhere.cf-num / .is-numPlex Sans, tabular figures. Right-aligned in table columns, left-aligned in property lists. Mono only for formulas, versions and keys.

Resize handle

One component, .cf-resize, in three positions: a visible corner grip (is-se, focusable) and two invisible edge zones (is-e, is-s) that show a blue line on hover, as in Figma. The host's data-cf-resizable sets the axis. One controller, cf-resize.js, handles pointer, keyboard (Arrow = 8px, Shift+Arrow = 1px), snapping and the live W × H readout.
